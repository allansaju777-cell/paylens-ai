# PayLens AI

## AI-Powered Business Finance Assistant

PayLens AI is an AI assistant that helps business owners understand their payment data without manually going through spreadsheets or complicated reports.

Users can ask questions in normal language, such as:

* How much revenue did we make?
* Who are our top customers?
* Which product is performing the best?
* How many payments failed?
* Are there any unusual transactions?

The application analyzes the transaction data and uses Gemini to turn the results into a simple, understandable answer.

## Why I Built This

Businesses can have thousands of payment transactions, making it difficult to quickly find useful information.

I wanted to build a system where a business owner could simply ask a question about their finances and get an answer without needing to manually analyze the data.

## Features

### Revenue Analysis

Calculates the total revenue generated from successful payments.

### Customer Analysis

Identifies the customers who have spent the most.

### Product Performance

Compares the revenue generated by different products.

### Failed Payment Analysis

Shows the number of failed payments and the amount associated with them.

### Unusual Transaction Detection

Finds unusually large transactions that may need further review.

This feature does not claim that a transaction is fraudulent. It only identifies transactions that could be worth investigating.

### Natural Language Questions

Users can interact with the financial data by simply asking questions instead of manually searching through the dataset.

For example:

> Which product makes the most money?

The AI determines which financial tool is needed and returns the result in a simple format.

## How It Works

The basic flow of the application is:

```text
User
  |
  v
Streamlit Dashboard
  |
  v
Gemini AI
  |
  v
Function Calling
  |
  v
Financial Analysis Tools
  |
  v
Transaction Data
  |
  v
Gemini AI
  |
  v
Final Answer
```

For example, when a user asks:

> How much revenue did we make?

Gemini understands that it needs revenue information and calls the revenue analysis function.

The Python function calculates the actual revenue from the transaction data.

The result is then sent back to Gemini, which explains it to the user.

This helps prevent the AI from simply guessing financial numbers.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/paylens-ai.git
cd paylens-ai
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Install the dependencies

This project uses `uv` for dependency management.

```bash
uv sync
```

### 3. Add your Gemini API key

Create a file named `.env` in the project directory.

Add:

```text
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Replace `YOUR_GEMINI_API_KEY` with your actual Gemini API key.

Do not upload the `.env` file to GitHub.

### 4. Run the application

```bash
uv run streamlit run app.py
```

The application will open in your browser.

## Why Function Calling?

Function calling is one of the main parts of PayLens AI.

Instead of asking Gemini to calculate or guess financial information itself, the application gives Gemini access to specific Python functions.

The process looks like this:

```text
User asks a question
        |
        v
Gemini understands the question
        |
        v
Gemini selects the required function
        |
        v
Python function analyzes the data
        |
        v
The result is returned to Gemini
        |
        v
Gemini explains the result
```

This allows the AI to work with the actual transaction data instead of making up financial values.

## Security


Never commit or publicly share your Gemini API key.
